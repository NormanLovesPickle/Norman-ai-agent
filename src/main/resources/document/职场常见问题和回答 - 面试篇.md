# 职场常见问题和回答 - 面试篇

#### 面试时如何谈薪资？
先了解市场行情和岗位薪资范围。被问期望薪资时，可反问"贵司该岗位的预算范围是多少"。给出区间而非具体数字，如"根据市场行情，期望在20-25K"。强调能力与价值，而非个人需求。拿到offer后还有谈判空间，可综合福利、发展做决策。推荐课程：[《薪资谈判技巧》](https://www.codefather.cn)。

#### 面试官问"你的缺点是什么"怎么答？
选择与岗位不冲突、可改进的缺点。如"有时过于追求完美导致效率受影响，正在学习优先级管理"。避免说"没有缺点"或暴露致命短板。结尾可补充改进措施，展现自我认知和成长意愿。推荐课程：[《面试常见问题应对》](https://www.codefather.cn)。

#### 如何回答"为什么离开上家公司"？
保持客观中立，不抱怨前司。可强调职业发展、平台机会、家庭原因等。如"希望寻求更大挑战""希望深耕某一领域"。避免涉及薪资纠纷、人际关系等敏感话题。展现积极向上的职业态度。推荐课程：[《离职原因话术》](https://www.codefather.cn)。

#### 群面/无领导小组讨论如何脱颖而出？
提前了解题型，练习时间把控和角色分工。主动承担计时、记录等角色，展现组织能力。发言要有逻辑，可先总结他人观点再补充。尊重他人，避免抢话或贬低队友。适时推动讨论进程，提出建设性方案。推荐课程：[《群面技巧与实战》](https://www.codefather.cn)。
