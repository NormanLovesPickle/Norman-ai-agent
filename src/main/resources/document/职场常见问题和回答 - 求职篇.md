# 职场常见问题和回答 - 求职篇

#### 如何写好一份吸引HR的简历？
简历要突出与岗位匹配的核心能力。使用STAR法则描述项目经验：情境(Situation)、任务(Task)、行动(Action)、结果(Result)。量化成果，如"通过优化流程使效率提升30%"。关键词与JD保持一致，便于ATS筛选。控制在一页以内，重点突出最近3年经历。推荐课程：[《简历优化与投递技巧》](https://www.codefather.cn)。

#### 投递简历后石沉大海怎么办？
检查简历与岗位匹配度，针对性修改关键词。拓展投递渠道：官网、招聘APP、内推、猎头。优化投递时间，工作日上午投递效果更好。跟进投递状态，一周后可礼貌询问HR进度。复盘面试失败经历，持续优化简历和面试表现。推荐课程：[《高效求职策略》](https://www.codefather.cn)。

#### 如何准备一场技术面试？
梳理项目经历，准备2-3个可深入展开的案例。复习岗位要求的技术栈，刷LeetCode保持手感。准备行为面试问题：团队协作、冲突处理、项目难点。了解公司业务和产品，准备"为什么选择我们"的回答。模拟面试，录音复盘改进表达。推荐课程：[《技术面试通关指南》](https://www.codefather.cn)。

#### 转行跳槽如何弥补经验不足？
突出可迁移能力：项目管理、沟通协作、学习能力。通过副业、开源贡献、个人项目积累相关经验。考取行业认证增加可信度。在简历和面试中强调快速学习能力和行业热情。选择门槛相对较低的岗位作为切入点。推荐课程：[《职业转型实战》](https://www.codefather.cn)。
