# 职场常见问题和回答 - 晋升篇

#### 如何主动争取晋升机会？
明确晋升标准，对照差距制定提升计划。主动承担高价值项目，让成果可量化可见。定期与直属领导沟通职业发展诉求。建立跨部门影响力，获得更多支持。记录工作成果，为晋升答辩准备素材。推荐课程：[《职场晋升攻略》](https://www.codefather.cn)。

#### 和领导沟通不畅怎么办？
了解领导的沟通风格和关注点。汇报时结论先行，再展开细节。主动同步进度，减少领导追问。有分歧时先倾听，再表达自己的考虑。选择合适时机沟通，避免情绪化表达。推荐课程：[《向上管理技巧》](https://www.codefather.cn)。

#### 如何应对职场PUA或不合理要求？
明确边界，区分合理要求与过度压榨。保留沟通记录，必要时寻求HR或上级支持。提升专业能力，增加不可替代性。评估公司文化，考虑是否值得长期留下。保护身心健康，必要时寻求心理咨询。推荐课程：[《职场边界与自我保护》](https://www.codefather.cn)。

#### 跳槽时如何谈涨薪？
基于市场数据和自身价值提出合理涨幅。强调新岗位的挑战和贡献预期。可争取签字费、股票等补充。拿到多个offer时可适度博弈，但避免过度拉扯。综合考虑平台、发展、团队，薪资非唯一因素。推荐课程：[《跳槽涨薪策略》](https://www.codefather.cn)。
